# Release Notes

What each version changes. The release workflow uses the page of the tagged version
(`book/src/release_notes/<version>.md`) as the text of the GitHub release.

- [0.3.1 (unreleased)](0.3.1.md): each database's MCP instructions, tools and saved-query
  tools on the multi-database `/mcp` endpoint.
- [0.3.0](0.3.0.md): safe concurrent changes, the directory as the security
  boundary, `start`/`stop`/`status`, shorter names, grants on aliases, the MCP and Database
  settings tabs, recovery after a crash, server backups, OpenAPI, Hugging Face model
  downloads, release binaries with installers, crates.io and a Dockerfile; on Graphersal 0.9.0.
- [0.2.0](0.2.0.md): access control (users, tokens, grants), persistent sessions, query limits
  and the memory ceiling, the backup root, the import inbox.
- [0.1.0](0.1.0.md): the first version.
